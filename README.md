# CyberHUDQuest3

Minimal Meta Quest 3 mixed-reality HUD prototype.

## What it does
- Launches as a Quest immersive app.
- Enables color passthrough.
- Shows a transparent head-locked cyberpunk-style HUD.
- No camera access, AI, object recognition, microphone, network calls, or scene scanning.

## Build
Designed for Android API 34, JDK 17, Gradle 9.4.1, Android Gradle Plugin 8.11.1, Kotlin 2.1.0, Meta Spatial SDK 0.14.0, and NDK 27.0.12077973.

The included GitHub Actions workflow builds a debug APK in the cloud.
